Quantumult是一款专为iOS设备设计的网络调试工具，它不仅仅是一个简单的代理应用，更是一个功能强大的网络优化平台。它支持多种协议（如SSL/TLS、HTTP/2等），能够显著提升网络安全性、隐私保护以及访问速度。

1.2 Workflow的核心概念

Workflow是Quantumult中的一项革命性功能，它允许用户根据特定条件创建自动化操作流程。想象一下，当你访问某个网站时，Quantumult可以自动切换代理、记录日志，甚至处理错误——这一切都可以通过Workflow实现。

第二章：从零开始设置Quantumult Workflow

2.1 安装与初步配置

  1. 下载Quantumult：在App Store中搜索“Quantumult”并安装。
  2. 基础设置：打开应用后，进入设置界面，熟悉Quantumult的基本功能，如代理配置、规则管理等。

2.3 设置触发器

触发器是Workflow的核心，它决定了Workflow何时执行。常见的触发器包括：
- 时间触发器：在特定时间执行操作（如每天上午9点切换代理）。
- 请求触发器：当访问特定网站时触发（如访问Netflix时自动切换至海外代理）。
- 位置触发器：根据设备的地理位置触发（如离开家时关闭某些代理规则）。

示例：
如果你想在访问YouTube时自动切换到高速代理，可以设置一个请求触发器，匹配YouTube的域名。

2.4 添加操作

触发器确定后，下一步是定义Workflow的具体操作。Quantumult支持多种操作类型：
- 代理切换：将流量路由到指定的代理服务器。
- 脚本执行：运行自定义脚本（如修改请求头、拦截广告等）。
- 通知提醒：发送推送通知，告知用户Workflow的执行状态。

示例：
为YouTube请求触发器添加“切换至高速代理”操作，确保视频流畅播放。

创建Workflow后，务必进行测试以确保其按预期运行：

3. 优化性能：如果发现延迟或错误，尝试简化规则或调整触发条件。

3.1 合理安排触发条件

过多的触发器可能导致Quantumult频繁执行操作，影响设备性能。建议：
- 合并相似规则：将多个网站的代理规则合并为一个通用规则。
- 使用通配符：通过通配符（如*.google.com）匹配多个子域名，减少规则数量。

3.2 编写简洁高效的规则

复杂的规则不仅难以维护，还可能降低响应速度。遵循以下原则：

- 优先使用内置功能：Quantumult内置了许多优化功能（如DNS缓存），无需通过脚本实现。

3.3 定期维护与更新

网络环境不断变化，Workflow也需要与时俱进：

FAQ

如何优化 Clash 的 DNS 设置？
在 Clash 中使用自定义 DNS 可以加快域名解析速度。建议使用 doh（DNS over HTTPS）或 dot（DNS over TLS）配置方式，既能提升速度，也能保护隐私防止 DNS 泄露。
Matsuri 节点延迟排序功能如何使用？
Matsuri 定期测速节点延迟，并结合策略组自动选择延迟最低的节点。用户无需手动切换节点，即可保持高速访问，提高网页、视频和游戏体验的稳定性。
QuantumultX 可以按协议类型分流吗？
支持。用户可按 TCP、UDP 或特定应用协议分流流量，结合策略组，实现游戏加速、视频优化或广告屏蔽等定制化网络策略，提高访问速度和稳定性。
Hysteria2 协议的主要特点是什么？
Hysteria2 是新一代基于 QUIC 的高速代理协议，支持自适应拥塞控制和零 RTT 连接。相比传统 TCP 协议，它能在高延迟或丢包环境下保持稳定速度，特别适合跨境访问或实时传输场景。
WinXray 如何保证视频流畅播放？
WinXray 会结合延迟检测和策略组选择最佳节点转发视频流量。通过自动切换低延迟节点，可保证在线视频播放顺畅，减少卡顿和缓冲，提高整体体验。
Nekobox 和 Nekoray 有何关系？
Nekobox 是 Nekoray 的移动端衍生版，界面简洁，主要适配 Android 平台。两者使用同样的核心逻辑与配置结构，因此订阅文件和节点信息可以兼容共享。
Mellow 如何配置透明代理？
Mellow 的透明代理功能可通过 TUN 模式或 WinDivert 实现。启用后系统流量会自动通过代理转发，无需手动设置浏览器代理，适合全局科学上网场景。
Sing-box 的 DNS 模块如何工作？
Sing-box 内置 DNS 模块，支持 fake-ip 模式和纯直连模式。它可根据规则选择不同的上游 DNS 服务，从而实现国内外域名智能分流，减少访问延迟。
为什么使用 CDN 后仍然能被封？如何规避？
若 CDN 回源 IP 或配置不当可能泄露真实服务器信息，或者 CDN 本身被目标防火墙识别。应启用完整的反向代理配置、隐藏源站 IP 与禁用不必要的服务，必要时使用多级中转或更换 CDN 供应商。
Nekoray 支持节点订阅批量更新吗？
支持。用户可通过订阅 URL 批量更新节点，程序会自动下载并替换旧节点。定期更新保证节点列表始终可用，减少手动维护，提高使用效率和便利性。
