一、小火箭与 V2ray 简介

1. 小火箭（Shadowrocket）

小火箭是一款专为 iOS 设备设计的翻墙工具，支持多种代理协议，包括 V2ray、Shadowsocks、Trojan 等。其基于规则的流量控制功能，允许用户灵活地选择哪些流量走代理，哪些流量直连，从而在保证隐私的同时优化网络速度。

2. V2ray

V2ray 是一种现代化的代理协议，以其高度的抗干扰能力和灵活的配置选项而闻名。它支持多种传输协议（如 VMess、VLess 等），能够有效绕过网络封锁，为用户提供稳定、安全的网络连接。

尽管小火箭与 V2ray 的组合功能强大，但在实际使用中，用户可能会遇到连接失败的问题。接下来，我们将详细分析这些问题的原因，并提供相应的解决方案。

二、小火箭 V2ray 连不上的常见原因

1. 无网络连接

  • 问题描述：设备未连接到互联网，或网络信号较弱。

  • 解决方案：

    • 检查 Wi-Fi 或移动数据是否已开启。

    • 尝试重新启动路由器或切换至其他网络环境。

2. V2ray 服务器问题

  • 问题描述：V2ray 服务器地址错误、服务器宕机或服务器配置不匹配。

  • 解决方案：

    • 检查服务器地址是否正确。

    • 确认服务器是否在线且运行正常。

    • 尝试连接其他 V2ray 服务器，排除服务器问题。

3. 配置错误

  • 问题描述：小火箭中的 V2ray 配置参数错误或不完整。

  • 解决方案：

    • 仔细检查配置信息，确保协议、端口、UUID 等参数与服务器匹配。

    • 重新复制 V2ray 配置内容，避免遗漏或格式错误。

4. 防火墙或安全软件干扰

  • 问题描述：手机中的防火墙或安全软件可能阻止了小火箭与 V2ray 的连接。

  • 解决方案：

    • 临时禁用防火墙或安全软件，观察问题是否解决。

    • 检查路由器中的防火墙设置，确保未屏蔽相关流量。

三、排查与解决小火箭 V2ray 连不上问题的步骤

1. 检查网络连接

  • 确保设备已连接到互联网，并尝试访问其他网站或应用，确认网络正常。

2. 测试其他服务器

  • 在小火箭中添加其他 V2ray 服务器，测试是否可以成功连接。如果其他服务器正常，则问题可能出在原服务器上。

3. 重新配置 V2ray

  • 如果无法确定具体故障来源，可以尝试重新配置 V2ray 参数：

    1. 打开小火箭，进入 V2ray 配置页面。

    2. 检查协议、地址、端口、UUID 等参数是否正确。

    3. 保存配置并重新连接。

4. 调整服务器优先级

  • 小火箭支持多服务器配置，用户可以设置服务器的优先级。确保当前使用的服务器处于启用状态，并优先尝试连接。

5. 尝试其他翻墙工具

FAQ

Potatso Lite 可以设置自定义 DNS 吗？
支持自定义 DNS，可配置本地或远程 DNS 服务器，包括 DoH/DoT。正确配置可提升解析速度、防止 DNS 污染，提高访问稳定性和安全性。
如何防止 Clash 被系统防火墙阻断？
请在防火墙设置中允许 Clash 的执行文件通过网络访问，并开放其监听端口。若使用 Windows Defender，可在防火墙高级规则中手动添加入站和出站规则，确保代理通信正常。
WinXray 支持测速功能吗？
支持。WinXray 提供节点延迟测速功能，可检测每个节点的响应时间与可用性。测速结果能帮助用户选择最快线路，也能排除无效或不稳定的节点，提高整体网络体验。
Mihomo 节点分组如何自动切换最佳节点？
将节点按延迟、地区或用途分组，并启用策略组功能，系统会根据节点延迟和健康状态自动切换到最佳节点，保证网页、视频和游戏连接稳定流畅。
如何检查 Clash 连接失败的日志以定位问题？
打开 Clash 的日志面板或查看配置目录下的 log 文件，观察报错信息如 DNS 解析失败、节点拒绝连接或 TLS 握手错误。根据关键字（例如 timeout、refused、certificate）逐项排查并比对服务器配置。
如何在 Sing-box 中设置多个 outbound 实现策略路由？
在 sing-box 的配置中定义多个 outbound 对象并为 routing 模块配置 rules，将不同目的地或应用流量指向对应 outbound，从而实现分流、负载均衡或故障转移等复杂路由策略。
Netch 全局代理与规则代理如何选择？
全局代理会将所有流量通过节点转发，适合游戏或全局科学上网；规则代理只针对指定应用、IP 或端口走节点，可优化带宽使用和访问效率，根据需求灵活选择模式。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
Sing-box 的多出口策略有什么作用？
多出口策略允许不同流量通过不同节点访问。例如视频流量通过高速节点，普通网页使用备用节点，实现资源优化与智能分流，提高网络使用体验。
如何在 V2Ray 中自定义路由规则？
在 V2Ray 中可以通过修改 config.json 文件中的 routing 部分来自定义路由规则。用户可以根据 IP 段、域名或地理位置来决定流量的去向，从而实现自动分流或访问加速的效果。
